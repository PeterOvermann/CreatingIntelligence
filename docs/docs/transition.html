CIRCUIT COMPONENTS

transition


State transition memory component, learning heteroassociations within a shared representational space.

See also: https://creatingintelligence.org/#state-transition-memory

Details and properties

  • Stores heteroassociations A → B, where A and B share the same representational space.
  • Receives the teaching signal B from the first half of its receive blocks, and the query A from the second half.
  • Learns A → B whenever the teaching signal is non-empty. In this case, the teaching signal takes the place of the retrieved pattern (teacher forcing).
  • Retrieves a pattern from memory if the teaching signal is empty.
  • Uses update rule plugins to control how the retrieved (or taught) pattern interacts with the query.
  • Retrieved patterns are valid queries: routed back through a feedback path, the component generates learned trajectories.
  • Controls sparsity through stochastic subsampling mechanisms.
  • Resolves multiset and inhibitory input prior to processing.
  • Supports multiple data blocks. Each output block requires a matching teaching block and a matching query block.


Property Default Description
send required [integer,...] representing one or more output slots
receive required teaching slots followed by query slots, each matching send, with optional pathway tags
plugin replacement update rule
threshold automatic relative pattern matching threshold
rate_limit unlimited subsample the query if it exceeds the specified relative rate limit (applies to storage and retrieval)
decimate 1 proportional stochastic decimation, applied to the query during retrieval


Use standard style options to customize the component’s appearance in circuit schematics.

Note on matching thresholds: with the default threshold, a query consisting of a single symbolic token (SHR) can match a stored key that bundles several tokens. Where a transition must only fire on the complete key, for example a state combined with an input symbol, set threshold to 1.0.

State transitions with replacement update

As the default update rule for the transition component, replacement returns the retrieved pattern B. In a teaching cycle, it returns the teaching signal.

In the following circuit, the first input provides the teaching signal and the second input the query. Storing the transitions A → B and B → C, then querying with A, returns B.

State transitions with complement update

As a plugin for the transition component, the complement update rule removes the query pattern from the retrieved pattern, returning only the elements that the transition adds to the query. This matters where the target pattern overlaps with the query, for instance in production rules operating on bundles.

The following circuit routes the output back to the query input, merging it with external input. Once a query starts the process, the circuit follows the stored transitions A → B → C → D cycle by cycle, and terminates when a state has no stored successor.

The same feedback path supports learning: presenting A as the query and then B, C, D as consecutive teaching signals stores the entire chain, because each teaching cycle returns the taught pattern, which becomes the next query.

Source code

def transition(config):
    """
    receive: k teaching blocks (B), followed by k query blocks (A).
    send:    k output blocks, matching the teaching and query blocks.

    If B is non-empty, store A -> B and use B as the retrieved value
    (teacher forcing). Otherwise retrieve Y from A.
    Returns updaterule(Y, A), split into blocks.
    """
    plugin_factory = config.get("plugin", replacement)

    if isinstance(plugin_factory, str):
        # Resolve string name to function dynamically
        import sys
        plugin_factory = getattr(
            sys.modules[__name__],
            plugin_factory,
            replacement)

    plugin = plugin_factory(config)

    send_blocks = config.get("send_blocks", [])
    receive_blocks = config.get("receive_blocks", [])
    k = len(send_blocks)
    dims = [b[0] for b in send_blocks]

    # Memory hyperparameters: A from the query blocks, B from the
    # teaching blocks. The "paired" check guarantees matching dimensions.
    teach_blocks = receive_blocks[:k]
    query_blocks = receive_blocks[k:]
    params_A = [sum(b[0] for b in query_blocks),
                sum(b[1] for b in query_blocks)]
    params_B = [sum(b[0] for b in teach_blocks),
                sum(b[1] for b in teach_blocks)]
    pop = params_A[1]

    # Limit size of the query pattern, relative to pop. Applies to both
    # storage and retrieval. Default: total input dimension (no limit).
    if "rate_limit" in config:
        absratelimit = round(pop * config["rate_limit"])
    else:
        absratelimit = sum(dims)

    # Proportional stochastic subsampling, applied to the query only.
    decimation = config.get("decimate", 1.0)

    m_config = dict(config)
    m_config.update({
        "A_parameters": params_A,
        "B_parameters": params_B
    })

    # Memory backend
    M = Memory(m_config)

    def f(*blocks):
        # Join partitions and apply inhibition
        B = resolve_block_join_normal(list(blocks[:k]), dims)
        X = resolve_block_join_normal(list(blocks[k:]), dims)

        # Limit the rate of incoming positives
        if len(X) > absratelimit:
            X = sorted(
                rng.choice(
                    X,
                    size=absratelimit,
                    replace=False).tolist())

        if B:
            # Instructed learning with teacher forcing: the teaching
            # signal takes the place of the retrieved pattern.
            M["store"](X, B)
            Y = B
        else:
            # Proportional decimation of the query
            if decimation < 1.0:
                sample_size = math.floor(decimation * len(X))
                Xdec = sorted(
                    rng.choice(
                        X,
                        size=sample_size,
                        replace=False).tolist())
            else:
                Xdec = X

            Y = M["retrieve"](Xdec)

        X_out = plugin["updaterule"](Y, X)
        X_out = sorted(list(set(X_out)))

        return tuple(multiset_block_split(X_out, dims))

    result = dict(plugin)
    result.update({
        "function": f,
        "label": plugin.get("label", "") + "●",
        "checks": ["paired"],
        "shape": "square", "fill": 14
    })
    result.update(M)

    return result
