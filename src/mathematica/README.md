### General Information

This Mathematica implementation of the *Creating Intelligence* framework is functionally
equivalent to the [Python](../python) package.

The Topological Assoicative Memory kernel is available in multiple interchangeable versions:

- Memory Reference.m: A straight implementation of the core memory algorithm, useful as a starting point for derived work.
- Memory Mathematica.m: Performance-optimized, native Mathematica implementation.
- Memory FFI.m: Wrapper for the Standard C memory kernel (**recommended**).
- Memory CLT.m: Wrapper for the Standard C command line interface.


### Build and Installation Instructions

- Choose one of the Memory notebooks and click the `Install` button at the top.
- Open Circuits.nb and click the `Install` button.
